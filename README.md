# 赤色要塞自动计时脚本

这是用于《赤色要塞》（Jackal）的 LiveSplit 自动分段脚本，文件为 `Jackalautosplit.asl`。

## 功能

- 从标题画面进入关卡时自动开始计时。
- 每次出现 `STAGE CLEAR` 画面时自动分段。
- 第 6 关的大坦克被击毁时触发最终分段。
- 回到标题画面时自动重置计时器。
- 支持 Mesen 2.1.1、Mesen 0.9.9、MesenRTA（0.0.7），以及 `fceux-2.6.6-y320-Win64-汉化版 - Emucheat`。

## 使用方法

1. 安装并打开 [LiveSplit](https://livesplit.org/)。
2. 启动支持的模拟器，并运行《赤色要塞》对应 ROM。
3. 在 LiveSplit 中打开计时器设置，进入自动分段设置并加载 `Jackalautosplit.asl`。
4. 启动游戏。脚本识别到标题画面进入关卡后会自动开始计时。

> 如果 LiveSplit 无法加载脚本，请确认使用的是支持脚本的 LiveSplit 版本，并检查模拟器进程是否已经启动。

## 分段规则

脚本使用游戏内存状态判断事件，而不是根据画面识别：

- **开始**：游戏状态从标题画面切换到关卡开始动画。
- **第 1 至第 5 关**：游戏状态首次进入 `STAGE CLEAR` 画面。
- **第 6 关最终分段**：确认大坦克已经出现后，检测到 Boss 被击毁。
- **重置**：游戏从其他状态回到标题画面。

继续画面和非第 6 关状态不会触发最终分段，能够避免上一次游戏残留状态造成误分段。

## 注意事项

- Mesen 版本必须与脚本支持的版本一致。脚本会通过 `MesenCore.dll` 的 SHA-1 自动识别版本，未知版本不会正常工作。
- FCEUX 仅支持 `fceux-2.6.6-y320-Win64-汉化版 - Emucheat`，其他 FCEUX 构建不保证兼容。
- 请先启动模拟器，再让 LiveSplit 尝试连接游戏进程。
- 脚本刷新频率为每秒 60 次；实际计时结果仍取决于 LiveSplit、模拟器和 ROM 设置。
